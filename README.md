## 🎓 Featured Project

### 🏗️ AI-Powered Web Project Structure Generator

Proyecto de investigación y desarrollo realizado como Trabajo Final de Máster.

Aplicación que utiliza inteligencia artificial para generar estructuras base de proyectos React siguiendo patrones arquitectónicos.

**Technologies:** React · Python · FastAPI · Hugging Face · Gemma · LoRA

**Key Features:**

- Generación de estructuras MVC y Clean Architecture.
- Integración de un modelo de lenguaje ajustado con LoRA.
- Validación automatizada de estructuras generadas.
- Exportación de proyectos en formato ZIP.
- Arquitectura desacoplada entre frontend y backend.
